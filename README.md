# Basic Encryption & Decryption using Caesar Cipher

## Project Overview

This project is a simple implementation of the **Caesar Cipher** encryption technique using Python. It allows users to encrypt a message using a shift key and decrypt the encrypted message back to its original form. This project demonstrates basic cryptography concepts, string manipulation, and Python programming fundamentals.

---

## Objectives

- Encrypt plain text using the Caesar Cipher algorithm.
- Decrypt the encrypted text back to its original form.
- Understand the basics of data confidentiality and cryptography.
- Build a simple command-line application using Python.

---

## Features

- Encrypts user-entered messages.
- Decrypts encrypted messages.
- Supports both uppercase and lowercase letters.
- Preserves spaces, numbers, and special characters.
- Simple and easy-to-use command-line interface.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the integrated terminal.
4. Run the following command:

```bash
python main.py
```

5. Enter the message you want to encrypt.
6. Enter the shift value.
7. The program will display both the encrypted and decrypted messages.
